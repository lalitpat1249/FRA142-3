# FRA142-3
## Overview COUP GAME
- **ชื่อ** : COUP (เกมโค่นอำนาจ)
- **แนวเกม** : บอร์ดเกมแนว Bluffing ใช้จิตวิทยา และการจับโกหก
- **จำนวนผู้เล่น** : 4 คน
- **Platform ในการรันเกม** : Terminal
- **Tech Stack / Library ที่ใช้พัฒนา** : c++

## Rules
**1. เป้าหมายของผู้เล่น**\
คือต้องกำจัดการ์ด ของผู้เล่นคนอื่นให้หมด ใครที่เหลือรอดเป็นคนสุดท้ายจะเป็นผู้ชนะ

**2. เริ่มต้น**\
ผู้เล่นทุกคนจะได้รับเหรียญ 2 เหรียญและการ์ดตัวละคร คนละ 2 ใบ ซึ่งจะต้องไม่เปิดเผยให้ผู้อื่นเห็น การ์ด 2 ใบเปรียบเสมือน 2 ชีวิต ถ้าเสียการ์ดครบ 2 ใบ ถือว่าออกจากเกม

**3. การเล่นเกม**\
เมื่อถึงตาตัวเองผู้เล่นต้องเลือกกระทำ 1 Action หรือจะสามารถประกาศใช้ความสามารถของตัวละครใดก็ได้ โดยไม่จำเป็นจะต้องมีการ์ดใบนั้นอยู่ในมือ

**4. การท้าทาย หรือ Challenge** \
ผู้เล่นสามารถท้าทายผู้เล่นคนอื่นได้ทุกเมื่อ หากคิดว่าผู้เล่นคนนั้นโกหก ซึ่งจะเกิดขึ้นได้ 2 กรณีคือ
- **case 1** : ผู้ที่ถูกท้าทาย โกหก หรือ ไม่มีการ์ดใบนั้นจริงๆ
    - ผู้ถูกท้ายทายต้องเลือกหงายการ์ดในมือ 1 ใบ
    - Action ที่ประกาศใช้ จะเป็นโมฆะ
- **case 2** : ผู้ที่ถูกท้าทาย พูดจริง หรือ มีการ์ดใบนั้นจริงๆ
    - ผู้ถูกท้าทายจะต้องเปิดการ์ดใบนั้นให้ดู
    - วางไว้กองกลางและหยิบใบใหม่ขึ้นมา
    - ผู้ที่ท้าทายจะต้องเลือกเปิดการ์ดตัวเอง 1 ใบ
    - Action ที่ประกาศใช้ ถือว่าสำเร็จ

**5. การขัดขวาง หรือ Block**\
ผู้เล่นสามารถขัดขวางผู้เล่นคนอื่นได้ทุกเมื่อ เพื่อหยุด Action นั้นได้ การประกาศ Block ก็สามารถถูกผู้เล่นคนอื่น Challenge ได้เช่นกันว่ามีการ์ดสำหรับ Block จริงหรือไม่

## How to play
**Start Game:** ระบบสับการ์ด แจกเงินคนละ 2 เหรียญ และแสดงการ์ดลับให้ผู้เล่นแต่ละคนเห็นบนหน้าจอตัวเอง

**Turn Start:** ระบบวนลูปเริ่มตาของผู้เล่น (เช่น Player 1)

**Choose Action:** ผู้เล่นเลือกคำสั่งผ่าน Terminal (พิมพ์ตัวเลข 1-7):

    [1] Income : รับ 1 เหรียญ

    [2] Foreign Aid : รับ 2 เหรียญ

    [3] Tax : (อ้างเป็น Duke) รับ 3 เหรียญ

    [4] Assassinate : จ่าย 3 เหรียญ + เลือกเป้าหมายเพื่อกำจัด

    [5] Steal : เลือกเป้าหมายเพื่อขโมย 2 เหรียญ

    [6] Exchange : (อ้างเป็น Ambassador) เพื่อสลับเปลี่ยนการ์ด

    [7] Coup : จ่าย 7 เหรียญ + เลือกเป้าหมายเพื่อกำจัด (บังคับใช้หากมี 10 เหรียญขึ้นไป)

**ระหว่างเกม:**
ทุกครั้งที่มีการเลือก Action (ยกเว้น Income และ Coup) ระบบจะหยุดเกมชั่วคราวและถามผู้เล่นที่เหลือทุกคนว่า "จะ Challenge หรือ Block หรือไม่?"

หากมีการ Challenge หรือ Block เกิดขึ้น ระบบจะเคลียร์ผลลัพธ์ตามกฎข้อ 4 และ 5 ก่อน แล้วจึงดำเนิน Action ต่อ (หากไม่โดนยกเลิก)

**Next Turn / End Game:** วนลูปเปลี่ยนเทิร์นผู้เล่นไปเรื่อย ๆ ผู้ใดที่การ์ดคว่ำหมด 2 ใบจะถูกคัดออก จนกระทั่งเหลือผู้รอดชีวิตคนสุดท้าย ระบบจะประกาศผู้ชนะและจบเกม
